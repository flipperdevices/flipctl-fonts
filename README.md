# flipctl-fonts

Set of pixel fonts adapted for **FlipCTL**

**Font folder structure:**
```
- TrueType binary (`.ttf`)
- Glyphs source file (`.glyphs`)
- LICENSE file
```

Each font has its **own license**. See each font below and the `LICENSE` file inside its folder.

## Fonts

### [HaxrCorp 4090](HaxrCorp4090-FlipCTL/)

## Building

The `.glyphs` sources are edited in [Glyphs.app](https://glyphsapp.com). Export
to `.ttf` (or `.otf`) from Glyphs to regenerate the binaries.
